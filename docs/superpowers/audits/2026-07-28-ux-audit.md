## High

- [ ] Placeholder phone in `lib/constants.ts` / Navigation (`+971 50 123 4567`) undermines trust — replace with real number or remove tel CTAs until confirmed. Same number hard-coded in `Navigation.tsx`, `app/contact/page.tsx`, `app/snibbles/page.tsx`, `app/kitchen/menu/page.tsx`, and `WHATSAPP_ORDER_URL` (`wa.me/971501234567`). Contact page literally links “Phone +971 50 123 4567”.
- [ ] Homepage stacks duplicate kitchen/catering promos (`HomePromoBanner` x2 + dual “Kerala at your door / Feeding your gathering” cards + `HomeOrderStrip` + `HomeExploreStrip` + `ClosingCtaBand`) — dilutes conversion. User sees Plan an event / Visit the kitchen / See today’s menu / Talk to us / Talabat / Noon / WhatsApp / See the menu repeatedly before the footer.
- [ ] Hero lacks dedicated secondary catering CTA (spec: primary kitchen/order, secondary catering). `TimeHero.tsx` only renders `config.cta` (e.g. “Order lunch”); secondary outline appears only for `closed` (“Browse the menu”), not catering. Chaya slot adds a Snibbles card overlay instead.
- [ ] Desktop nav links and mobile menu toggle use hover styles but no visible keyboard focus ring (`Navigation.tsx`: links lack `focus-visible:ring-*`; toggle uses `focus:outline-none` with no replacement). Keyboard users lose position in a 9-link nav.
- [ ] Contact form is a fake conversion path: `app/contact/page.tsx` `handleSubmit` only `console.log` + `alert(...)` — no API. Users believe they messaged the kitchen and nothing is delivered.
- [ ] Homepage first viewport fails brand test: sticky logo only; hero copy is rotating food captions (`HERO_CAPTION_ROTATIONS`) without a hero-level “Suja’s Kitchen” wordmark/name. Remove nav and the first screen could be any Kerala meal brand.

## Medium

- [ ] Body font Inter reads SaaS, not heritage editorial — swap to Karla (`app/layout.tsx` loads Inter as `--font-inter` and applies `inter.className` on `body`).
- [ ] Desktop nav has 9 text links (Home, Kitchen, Menu, Catering, Snibbles, Seasonal, Our Story, Blog, Contact) plus Call Us — crowded at ~1140px; consider overflow/more pattern or grouping Kitchen+Menu.
- [ ] Story sections over-use Card chrome: “How we make food” three truths (`HomeBelowFold.tsx`), Eat/Gather dual cards, and marketing pages wrap non-interactive story blocks in bordered cards/shadows.
- [ ] Marketing-page visual language fights the elevated home: `/catering`, `/snibbles`, `/kitchen/menu`, `/contact` use `font-bold` gray-900 headlines, decorative `w-24 h-1 bg-brand` rules, and blue/purple gradient icon chips (`from-blue-500`, `from-purple-500`) — opposite of quiet heritage editorial and brand-red discipline.
- [ ] Surface system split: home uses time-of-day `pageBg`; kitchen/seasonal use flat cream `#FFFBF0` + stone; catering/contact/snibbles/menu use white + gray-50 gradients. Cascade needs one surface language.
- [ ] Social proof is soft-broken: `/api/google-reviews` 500 (missing token); `HomeGoogleReviews` falls back to anonymous “Google reviewer” blurbs. Instagram API OAuth fails; feed shows generic “From the kitchen” tiles. Spec requires Google reviews as real proof.
- [ ] Mid-home `HomeExploreStrip` restates the full IA (kitchen, menu, catering, seasonal, story, journal) right after the heritage story — another CTA cluster before the user has committed to order or catering.
- [ ] Catering / menu / contact / snibbles heroes are oversized marketing slabs (`h-[70vh]`–`85vh`, often `min-h-[600px]`–`700px`) with generic titles (“Catering Services”, “Our Menu”, “Contact Us”) that overpower brand and bury the primary job.
- [ ] Seasonal notify path shows “Notifications unavailable” when mail is not configured (`SeasonalExperience` + `seasonalMailConfigured`) — dead-end for users trying to leave an email for Onam/window opens.
- [ ] Snibbles hero scroll fade/parallax (`app/snibbles/page.tsx` `opacity: 1 - scrollY / 500`, `translateY(scrollY * 0.2)`) does not check `prefers-reduced-motion` (unlike `ParallaxBanner`, which does).

---

## Low

- [ ] Decorative `HomeDivider` frequency between Featured, story, and Instagram — thin gradient bars that do not advance the narrative.
- [ ] Mobile Call Us control is `h-10 w-10` (40px) — under 44px touch-target guideline; toggle button width also ~40px at 375px.
- [ ] Chaya-time Snibbles promo in `TimeHero` is a floating Card on hero media (detached overlay) — conflicts with “no hero overlays / stickers” direction in the elevation spec.
- [ ] Footer omits phone (sensible while placeholder) but still leaves email-only contact; once real phone lands, keep a single source in `CONTACT` and avoid a second hard-coded copy in Navigation.
- [ ] Repeated end-of-page `PageCrossLinks` / `ClosingCtaBand` on almost every route — useful once, redundant when every page already pushed the same four doors.
- [ ] Menu PDF download handler comments admit placeholder behavior (`app/kitchen/menu/page.tsx`) — confirm assets resolve before promoting “Download” as a primary action.
- [ ] No horizontal overflow observed at 375px on contact/seasonal; keep watching image carousels (`AnimatedGallery` on catering) and Instagram sideways strip copy (“Scroll sideways for more”) for gesture discoverability.
